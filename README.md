# miniDaw

在瀏覽器裡運作、仿 Logic Pro 操作邏輯的數位音樂工作站（DAW）。可以錄音、用節拍器與預備拍、多軌編曲、在鋼琴捲簾與鼓機步進格裡編輯、在混音台混音，並內建 32 種樂器音色——鋼琴、鼓組、電鋼琴、吉他、貝斯、弦樂、銅管等使用開放授權的真實錄音取樣，合成器類則即時合成。右側的 **曲風編曲教練** 會依照你選的曲風（18 種），解釋這種音樂的編曲特色，並一步一步帶你把鼓、貝斯、和弦、配器、旋律與混音做出來——每一步都能一鍵生成，再照自己的想法修改。

A Logic Pro–style DAW for the browser: audio/MIDI recording, metronome & count-in, multitrack arrangement, piano roll, drum step sequencer, mixer with inserts and sends, 31 synthesized instruments, and a genre arrangement coach (18 genres, Traditional Chinese UI).

## 快速開始

```bash
npm install
npm run dev          # 開發伺服器，打開終端機顯示的網址
```

| 指令 | 用途 |
| --- | --- |
| `npm run dev` | 開發模式 |
| `npm run build` | 打包到 `dist/`：可安裝、可離線使用的版本（放到任何 HTTPS 靜態主機，例如 GitHub Pages） |
| `npm run build:single` | 打包成單一 HTML 檔 `dist-single/index.html`，不需要伺服器 |
| `npm test` | 單元測試（樂理、音色合成調音準確度、曲風生成、檔案格式、壓縮器模型） |
| `npm run e2e` | 端到端測試：在無頭 Chromium 裡實際播放、錄音、匯出、模擬手機與離線並截圖（需先 `npm run build`） |
| `npm run icons` | 重新產生 App 圖示（`public/icons/`） |

## 離線版（不需要網路）

### 安裝到手機或電腦，當成 App 用（推薦）

`npm run build` 產生的版本是 PWA：第一次開啟時會把整個程式存到裝置上，之後沒有網路也能開啟、播放、錄音和匯出，作品存在裝置裡（IndexedDB）。

1. **放到網路上一次**：最簡單是用這個專案的 GitHub Pages —— 在 GitHub 專案的 Settings → Pages → Build and deployment → Source 選「GitHub Actions」，之後每次推到 `main` 都會自動部署（也可以在 Actions 頁面手動執行「Deploy to GitHub Pages」）。網址會是 `https://<帳號>.github.io/<專案名稱>/`。也可以把 `dist/` 放到任何 HTTPS 靜態主機。
2. **用手機打開網址**，看到「已可離線使用」的提示就完成快取了。
3. **加入主畫面**：iPhone／iPad 用 Safari 的「分享」→「加入主畫面」；Android 用 Chrome 選單的「安裝應用程式」，或 miniDaw 選單裡的「安裝到主畫面（離線使用）」。

之後從主畫面開啟就像一般 App，沒有網路也能用。有新版本時會在背景下載，下次開啟時套用。

### 單一 HTML 檔（電腦）

`npm run build:single` 會產生一個完全獨立的 `dist-single/index.html`（約 21 MB，內含全部錄音音色），複製到任何電腦用 Chrome／Edge／Firefox 直接開啟即可，不需要網路或伺服器（沒有網路時字型會改用系統字型）。

### 手機沒有聲音？

- iPhone／iPad 的側邊靜音開關原本會讓網頁音訊靜音；miniDaw 會向系統要求「播放」音訊模式來避開，若仍沒有聲音，請關閉靜音開關並調高音量。
- 瀏覽器只允許「點擊之後」才能發出聲音：先點一下畫面或播放鍵即可。

## 功能

### 錄音
- **音訊錄音**：新增音訊軌 → 按音軌上的 ● 待命 → 按 `R`。使用 AudioWorklet 取得逐樣本精準的起始時間，並自動補償瀏覽器回報的輸入／輸出延遲，設定裡還能手動微調（錄音延遲補償）。
- **MIDI 錄音**：選取樂器軌後按 `R`，用電腦鍵盤（`⌘K` 開啟「鍵盤演奏」）或 USB MIDI 鍵盤（設定 → 啟用 MIDI 輸入，支援延音踏板）演奏。開啟循環時會把每一圈彈的音符合併在同一個片段裡，適合一層一層疊鼓。
- **輸入監聽**（耳機圖示）、輸入音量表、選擇錄音裝置。

### 節拍器與走帶
- 節拍器（`K`）有重音、可設定只在錄音時響；錄音前可以有 1–2 小節預備拍。
- 播放／停止（空白鍵）、回到開頭（Enter）、逐小節移動（`,` `.`）、循環範圍（`C`，在時間尺上拖曳設定）。
- LCD 顯示小節.拍.格.Tick 與時間，速度可拖曳或點擊輸入，拍號與調性可直接切換。
- 播放頭會補償輸出延遲，畫面與聲音對得上。

### 音軌與編曲
- 軟體樂器軌、音訊軌；拖曳片段移動（可跨音軌）、拉邊緣調整長度、Option 拖曳複製、`⌘D` 複製、`⌘B` 在播放頭分割、框選、靜音片段、重新命名。
- 段落標記（前奏／主歌／副歌…）：右鍵可以「循環播放這一段」「把這一段複製到歌曲結尾」，快速排出整首歌的結構。
- 拖放音訊檔、MIDI 檔、專案檔到音軌區即可匯入。

### 編輯器
- **鋼琴捲簾**：選取／畫筆／橡皮擦工具、框選、移動／調長度／複製音符、力度條、量化、移調、調性輔助線（標示目前調性的音），點琴鍵試聽。
- **鼓機步進格**：一行一個鼓件、一格一個 16 分音符，Shift 點擊重音、Option 點擊鬼音、拖曳連續畫。
- **音訊片段編輯**：波形、增益、淡入淡出、標準化。

### 混音台
- 每軌頻道條：效果器插槽（頻道等化器、壓縮器、破音、合唱、顫音／自動聲像、**側鏈抽吸**、Lo-Fi、立體延遲）、殘響／延遲傳送、聲像、推桿與立體聲音量表（含峰值保持與削波指示）、M／S／錄音待命。
- 殘響與延遲為傳送／返回匯流排（延遲與速度同步）；主輸出有限幅器與柔性削波保護。
- 效果器視窗附常用預設（人聲清晰、大鼓有力、電話效果、EDM 強抽…）與 EQ 頻率響應曲線、壓縮量表。

錄音取樣都來自開放授權的音色庫（多數為 CC0 公有領域，Salamander 鋼琴與 Wurlitzer 為 CC BY 3.0、尼龍吉他為 MIT），編曲教練的鼓組律動來自 Groove MIDI Dataset（CC BY 4.0），並依授權在 App 的「檔案 → 音色來源與授權」與 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) 標示作者、授權與修改內容。重新產生取樣：`python3 scripts/samples/build_samples.py`（需要 git、ffmpeg、numpy）；重新擷取鼓組律動：`python3 scripts/grooves/build_grooves.py`（需要 `pip install mido`）。

### 曲風編曲教練
流行、華語抒情流行、抒情慢歌、搖滾、金屬、鄉村／民謠、嘻哈 Boom Bap、Trap、Lo-fi Hip-Hop、R&B／Neo-Soul、浩室 House、EDM 電子舞曲、Synthwave、爵士 Swing、巴薩諾瓦、放克 Funk、City Pop、雷鬼。

每個曲風包含：速度範圍與律動（swing）、推薦調性、3–4 組常見和弦進行（可試聽、顯示實際和弦名稱）、曲式結構、配器與每個樂器的角色說明、混音建議與編曲小技巧。「跟著做」分成 11 個步驟：

1. 設定速度、拍號與調性 → 2. 規劃曲式段落 → 3. 鼓組 → 4. 貝斯 → 5. 和弦 → 6. 配器層次 → 7. 旋律 → 8. 編曲動態檢查 → 9. 混音 → 10. 錄音 → 11. 輸出

每個生成步驟都會依段落能量改變彈法（主歌較少、副歌較滿、段落結尾自動加過門、Build-up 小鼓漸密），和弦使用聲部進行（voice leading）、吉他使用真實和弦指型與刷弦時間差。所有結果都是可編輯的 MIDI，也可以一鍵復原。

示範編曲參考了公開的編曲／作曲資源，讓它「有審美」：

- **鼓：真人鼓手的律動**。流行、華語、抒情、搖滾、鄉村、Boom Bap、Lo-fi、R&B、放克、City Pop、爵士的鼓，取自 [Groove MIDI Dataset](https://magenta.tensorflow.org/datasets/groove)（Google Magenta，職業鼓手對著節拍器演奏的 13.6 小時錄音），保留鼓手自己的重音與微小的前後推拉。依曲風的典型節奏型挑出最道地的演奏，並依歌曲速度選最接近的一段；前奏與安靜的主歌改成邊擊（cross-stick）或拿掉小鼓，副歌換成同一位鼓手較滿的版本並加碎音鈸（搖滾、抒情、鄉村改打 Ride，流行加拍手與開鈸，City Pop 副歌換成 Disco 四四拍），過門是同一位鼓手在同一段演奏裡打的過門，進副歌用大過門、其他段落用短過門，最後一段以過門收在碎音鈸上。原本的 swing 會換成歌曲設定的 swing，和其他樂器對齊。電子曲風、金屬、雷鬼（One Drop）與巴薩諾瓦（邊擊 clave）資料集裡沒有夠道地的錄音，維持原本寫好的鼓型。
- **貝斯跟大鼓咬合**：流行、Lo-fi、R&B 的貝斯跟著鼓手的大鼓位置彈根音（鬼音大鼓不算），換和弦前用經過音帶進去；808 貝斯同樣對齊大鼓。
- **旋律照作曲原則寫**（參考 [Open Music Theory](https://openmusictheory.github.io) 的樂句結構與裝飾音章節）：4 小節為一個樂句、由 2 小節的動機構成——主歌是「呈示、變化重複、發展、收束」，副歌把 Hook 重複到記得住，導歌用上行模進推向副歌，橋段換音域；強拍放和弦音，弱拍用經過音與鄰音並以級進解決；每個樂句一個最高點，大跳之後反向級進回填，不跳三全音或超過八度；主歌音域低、像說話，副歌高、長音多；樂句尾在 2 或 5 級（開放）延續，副歌尾從 2 級落到主音（終止）；每個樂句之間留換氣，流行樂會把下一句的強拍提前半拍進來。副歌旋律每次出現都一樣（好記）。

### 匯出與匯入
- 匯出混音 WAV（16／24／32-bit、44.1／48 kHz、可標準化，16-bit 加三角抖動）、**分軌（Stems）ZIP**、**MIDI 檔**（可直接拖進 Logic Pro／GarageBand）。
- 匯入音訊檔、MIDI 檔（依 GM 音色自動選擇樂器）、專案檔。
- 專案自動儲存在瀏覽器（IndexedDB，含錄音）；也可以存成專案檔帶到別台電腦。

## 技術架構與效能優化

- **TypeScript + React + Vite**，狀態用 zustand + immer（結構共享的不可變資料，復原／重做只存快照，記憶體成本極低；拖曳等連續操作合併成一個復原步驟）。
- **錄音音色引擎**：多音域（multi-zone）× 力度層 × 輪替（round robin）取樣，依音高變速播放；鼓組有開合鈸互斥（choke）、缺的鼓件用相近鼓件移調補上；銅管依音符長短自動選斷奏或長音。取樣轉檔工具會混合麥克風、裁掉起音前的靜音、把 SFZ 迴圈展開成自然衰減、整組一起標準化（保留力度層之間的動態），並用頻譜自動檢查每個取樣的實際音高，避免八度標錯。瀏覽器解碼 MP3 時的編碼延遲各不相同，載入時會再對齊起音，確保鼓點準時。
- **合成音色**（也是錄音音色的備援）：吉他與貝斯用擴充 Karplus–Strong 物理模型（全通濾波器精確分數延遲，單元測試保證音準誤差 < 6 cents），鋼琴是帶非諧和泛音、雙段衰減與琴弦拍頻的加法合成（並做伸展補償），電鋼琴是 FM 合成，鼓組由各種振盪器、雜訊與濾波器即時算出。
- **背景合成**：樂器取樣在 Web Worker 裡平行算出，需要立即播放的優先處理；以多音域區（multi-sample zones）+ 變速播放減少記憶體，快取有 LRU 上限。音訊引擎在頁面載入後就開始預先合成，按下播放時聲音已經就緒。
- **力度分層**：每個音域預先合成「輕」「重」兩層（輕的較暗、琴槌與撥弦聲較少），不必再為每個音符掛濾波器；聲像改成每個樂器共用 5 條匯流排，一個音符只剩「取樣播放 + 音量包絡」兩個節點。密集的副歌離線輸出快了約 3 倍（6 軌流行副歌約 0.5 倍即時）。
- **靜音／未獨奏的音軌完全不排程音符**，分軌輸出與獨奏監聽都更省資源。
- **響度校準**：32 種音色都用 ITU-R BS.1770 響度（K 加權、門限，LUFS）量過，各自校正到同一個基準（−16 LUFS），換音色時不會忽大忽小；18 種曲風的推桿再依「旋律最突出、鼓與貝斯撐住、和聲與音墊在後」的比例逐軌量測設定，副歌混音約 −14～−16 LUFS，不會一直壓在限幅器上。
- **修正瀏覽器壓縮器的隱藏增益**：Web Audio 的 DynamicsCompressorNode 會自動加上補償增益（常見設定下 +6～+15 dB），開壓縮器就等於把音量推大。miniDaw 依規格精確算出並抵銷它（與 Chromium 實測誤差 < 0.01 dB，有單元測試），所以「補償增益」寫多少就是多少；鼓組的 Punch 旋鈕也只改變質感，整個範圍音量變化在 ±1 dB 內。
- **排程器**：「lookahead」排程搭配 Worker 計時器（背景分頁也不會被降速），循環、預備拍、速度變化時播放頭都保持連續。
- **同一套混音圖**同時用在即時播放與離線輸出（OfflineAudioContext），所以匯出結果和聽到的一致，且不受電腦效能影響。
- **錄音延遲補償**：AudioWorklet 記錄第一個樣本的確切時間，再扣掉輸入與輸出延遲。
- 側鏈抽吸用排程器預先寫好的增益自動化實作（Web Audio 沒有原生側鏈）。
- 主輸出有限幅器 + 柔性削波，避免輸出破音。
- 所有面板都支援深色／淺色主題、觸控操作（Pointer Events）與窄螢幕。

- 音訊片段不做時間伸縮（改速度時錄音不會跟著變長變短）。
- 尚未支援自動化曲線（automation）與第三方外掛（AU／VST）。
- 在 claude.ai 預覽環境裡無法使用麥克風、也不能離線；請用上面的離線版或本機 `npm run dev` 錄音。
